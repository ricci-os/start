## How to handle it

- Read this page before going deeper, even if you were given a direct link.
- Use the deepest layer you have access to. If you only have this page, you don't have operational context or permission to act on Matt's systems. Permissions are granted per agent and recorded in the private repo.
- Facts live at the deepest layer. The private repo is generated from Matt's local files, and the public repo is curated from both. Don't correct something at a shallower layer than where it's kept.
- Both public repos are readable by anyone and indexed by search engines. Don't add anything to them that Matt hasn't already made public: no addresses, phone numbers, account numbers, money figures, health details, employer information, or other people's names. If unsure, it belongs in the private repo or nowhere.
- Don't infer private facts, work context, or authority from public material.
