# Start

**Every agent working for Matt Ricci begins here.** This page is a pointer, nothing more. It tells you which layer of Matt's context you can reach and the rules that bind all of them.

## The three layers

| Layer | Where | Who can read it |
|---|---|---|
| 1 · Start | this page | everyone |
| 2 · Context | `github.com/ricci-os/ricci-context` (private) | agents Matt has granted access, by GitHub login or a token he issued |
| 3 · Local | Matt's own machines | an agent running on one of them; the private repo's README says what lives where |

Matt's public canon for the outside world (principles, working preferences, reading) is a separate repository: **[github.com/ricci-os/ricci-context-public](https://github.com/ricci-os/ricci-context-public)**. Read it for how he thinks. It is not where agents start, and it carries no operational context.

## Rules of the chain

1. **Start here, always.** If you were handed a deeper link, read this page once first.
2. **Go as deep as your access allows, and no deeper.** An agent without access to layer 2 has no operational context about Matt and no write authority anywhere. Write authority is granted per agent and recorded in layer 2.
3. **Facts are authored at the deepest layer and flow upward only by deliberate promotion.** Layer 3 is the source; layer 2 is generated from it; the public canon is hand-promoted. Never fix a fact at a shallower layer than where it lives.
4. **Treat the public layers with care.** This page and the public canon are world-readable and indexed. Nothing goes into either that Matt has not already made public by his own decision: no addresses, phone numbers, account identifiers, money figures, health details, employer internals, or third-party names. When in doubt the answer is layer 2, or nowhere.
5. **Public does not mean authoritative.** Do not infer private facts, employer context, or standing authority from anything public.
